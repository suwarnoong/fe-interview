# FE Interview — User Directory

A small React + TypeScript app: a searchable, filterable, paginated directory of
users backed by a (deliberately slow) mock API.

The app **works**, but users have reported a handful of problems. Open
`src/UserDirectory.tsx`, read the notes at the top, and improve it. Talk through
what you find as you go — how you diagnose and prioritize matters as much as the
fixes.

## Run

```bash
npm install
npm run dev   # open the printed localhost URL
```

Tip: have React DevTools open.

## Files

| File | Notes |
|---|---|
| `src/UserDirectory.tsx` | The component to work on. Start here. |
| `src/mockApi.ts` | The backend. Treat it as a real API — **don't edit it.** |

You're free to add files, hooks, or libraries if you think they help.
